A high-performance Vector Symbolic Architecture (VSA) implementation in pure Rust. Encodes syntactic AST structures, semantic role-filler pairs, and associative episodic memory into 10,000-dimensional hypervectors using circular convolution MAP (Multiply-Add-Permute) binding.

  • AVX2 L2 Normalization: Normalizes 10,000-D hypervectors in sub-microsecond latency via FMA sum-of-squares and broadcast inverse square root.
  • ItemMemory SQLite WAL: Transmutes raw 40KB vector slices into zero-overhead SQLite BLOB columns (WAL mode), with L1 FxHashMap RAM caching and L2 disk persistence.
  • Associative Semantic Recall: Performs sub-millisecond clean-up associative queries across thousands of stored memory patterns.

quantNN • Hypercomplex Quaternion Neural Network

A 4D hypercomplex neural network architecture in Rust based on Hamilton quaternion algebra ℙ. Employs exact analytical backpropagation preserving non-commutative geometry on S³ without finite-difference approximation.

  • Exact Analytical Hamilton Backprop: Closed-form parameter and input gradients: ∇W = ∇Y × X*, ∇X = W* × ∇Y, ∇B = ∇Y.
  • QuaternionAdamW Optimizer: Decoupled weight decay (W ← W - ηλW) with coordinate-wise first and second hypercomplex moment tracking.
  • Lie Algebra Geodesic Normalization (QuaternionLayerNorm): Normalizes quaternion activations onto the 3-sphere S³ with learnable affine parameters.
  • Dual Sparsity: Top-K sequence attention (75% sparsity) and Mixture-of-Experts parameter routing (50% sparsity).

Base-7 Interaction Combinator Engine (deen-heptal)

A radical departure from binary graph reduction. Replaces binary tree splitting (log&sub2; N) with an arity-7 concurrent fan-out (!7), flattening reduction trees from 20 levels down to ~7 levels for 10&sup6; concurrent nodes.

  • BendTT Affine Linearity Checker: Statically proves every variable is consumed at most once (≤ 1). Implicit duplication and contraction are formally forbidden.
  • Affine Wire Demolition: The 7th instruction slot flags instant register zeroing when a wire reaches its affine end-of-life, yielding zero-cost memory reclamation with zero garbage collection.
  • Dual Binary/Heptal VM: Maps 7 parallel reduction lanes across 256-bit AVX2 SIMD registers on binary silicon with cycle-accurate rdtsc profiling.
  • Mechanized Lean 4 Verification: Confluence and affine preservation formally proved in crates/deen-heptal/formal/heptal_ic.lean.
